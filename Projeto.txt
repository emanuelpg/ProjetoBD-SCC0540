1. DESCRICAO FINAL DO SISTEMA
============================================================
Sistema de gestão de eventos, como congressos, feiras, simpósios e
treinamentos, e dos espaços onde eles ocorrem, implementado em PostgreSQL. Cada evento
e cadastrado como uma edição independente, com período de realização, e pode ser
promovido por um ou mais promotores, pessoas físicas ou organizações, com registro do
valor e da data do patrocínio. A programação de um evento e formada por atividades, tais como
palestras, minicursos, workshops, painéis, entre outros, e cada atividade pode ter varias
sessões, cada uma com inicio, duração, termino calculado automaticamente, numero de
vagas, valor e espaço. Os espaços possuem capacidade maxima e um estoque de recursos, e cada 
sessão registra os recursos de que necessita. Participantes se credenciam nos eventos, indicando 
se atuam como organizadores, e a partir do credenciamento se inscrevem nas sessões como ouvinte,
instrutor ou palestrante; somente ouvintes ocupam vagas. O banco possui 14 tabelas,
domínios para CPF, CNPJ, CEP, e-mail, telefone, UF e valores monetários, um tipo
enumerado para os papeis e cinco triggers que impedem: sessões sobrepostas no mesmo
espaço, inscrições da mesma pessoa em sessões com horários sobrepostos, inscrições de
ouvintes acima do limite de vagas, sessões com mais vagas que a capacidade do espaço ou
alocadas em espaço sem os recursos exigidos, e pedidos de recursos indisponíveis no
espaço da sessão. Um protótipo em linha de comando, em Python, executa comandos em linguagem
natural para SQL com um modelo local via Ollama.
============================================================
2. DECISOES DE PROJETO
============================================================
Q1: Pessoas e organizações serão representadas separadamente, permitindo que vários promotores patrocinem vários eventos.
Q2: Os papeis são representados por meio do atributo "papel" na tabela de Inscrição e flag de organizar em Credenciamento
Q3: Uma atividade poderá possuir várias sessões (entidade fraca, PK = AtividadeId + NumeroSessao), cada uma com data, horário, espaço, duração, vagas e valor próprios.
Q4: Cada edição de um evento será cadastrada separadamente, permitindo acompanhar a participação em diferentes edições.
Q5: Um trigger verificará as inscrições e os limites de vagas da sessão e do espaço antes de aceitar novas inscrições.
Q6: Não serão preservadas alterações de programação preservadas no histórico, com isso, o update irá sobrescrever a sessão anterior.
Cada resposta Q1-Q6 deverá ocupar uma única linha.

-- 1. Dominios (tipos com regra de validacao reaproveitavel)
-- ------------------------------------------------------------

-- CPF: 11 digitos, somente numeros (sem pontos e traco)
CREATE DOMAIN dom_cpf AS CHAR(11)
    CHECK (VALUE ~ '^[0-9]{11}$');

-- CNPJ: 14 digitos, somente numeros
CREATE DOMAIN dom_cnpj AS CHAR(14)
    CHECK (VALUE ~ '^[0-9]{14}$');

-- CEP: 8 digitos, somente numeros
CREATE DOMAIN dom_cep AS CHAR(8)
    CHECK (VALUE ~ '^[0-9]{8}$');

-- E-mail: formato basico texto@texto.texto
CREATE DOMAIN dom_email AS VARCHAR(120)
    CHECK (VALUE ~* '^[^@[:space:]]+@[^@[:space:]]+\.[^@[:space:]]+$');

-- Telefone: DDD + numero, 10 ou 11 digitos
CREATE DOMAIN dom_telefone AS VARCHAR(11)
    CHECK (VALUE ~ '^[0-9]{10,11}$');

-- Unidade federativa
CREATE DOMAIN dom_uf AS CHAR(2)
    CHECK (VALUE IN ('AC','AL','AP','AM','BA','CE','DF','ES','GO','MA',
                     'MT','MS','MG','PA','PB','PR','PE','PI','RJ','RN',
                     'RS','RO','RR','SC','SP','SE','TO'));

-- Valores monetarios nao negativos
CREATE DOMAIN dom_dinheiro AS NUMERIC(12,2)
    CHECK (VALUE >= 0);

-- SESSAO (entidade fraca de Atividade: Atividade 1:N Sessao,
--         participacao total; Sessao N:1 Espaco, participacao parcial)
-- A PK e composta pela chave da entidade forte (AtividadeId) e pela
-- chave parcial NumeroSessao (1, 2, 3... dentro de cada atividade).
CREATE TABLE sessao (
    AtividadeId    INTEGER      NOT NULL,
    NumeroSessao   INTEGER      NOT NULL,      -- chave parcial
    EspacoId       INTEGER,                    -- pode ficar sem espaco definido
    Nome           VARCHAR(150) NOT NULL,
    DataHoraInicio TIMESTAMP    NOT NULL,
    Duracao        INTEGER      NOT NULL,      -- em minutos
    Vagas          INTEGER      NOT NULL,
    Valor          dom_dinheiro NOT NULL DEFAULT 0,

    -- Atributo gerado: termino da sessao, calculado a partir do inicio
    -- e da duracao. Facilita a verificacao de conflito de horario.
    DataHoraFim    TIMESTAMP GENERATED ALWAYS AS
                   (DataHoraInicio + make_interval(mins => Duracao)) STORED,

    CONSTRAINT pk_sessao PRIMARY KEY (AtividadeId, NumeroSessao),
    CONSTRAINT ck_sessao_numero  CHECK (NumeroSessao > 0),
    CONSTRAINT ck_sessao_duracao CHECK (Duracao > 0),
    CONSTRAINT ck_sessao_vagas   CHECK (Vagas > 0),
    CONSTRAINT fk_sessao_atividade
        FOREIGN KEY (AtividadeId) REFERENCES atividade (AtividadeId)
        ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT fk_sessao_espaco
        FOREIGN KEY (EspacoId) REFERENCES espaco (EspacoId)
        ON DELETE SET NULL ON UPDATE CASCADE
);

-- ------------------------------------------------------------
-- Trigger 0: Conflito de espaco
-- Duas sessoes nao podem ocupar o mesmo espaco no mesmo intervalo.
-- ------------------------------------------------------------
CREATE OR REPLACE FUNCTION fn_valida_conflito_espaco()
RETURNS TRIGGER AS $$
DECLARE
    v_conflito INTEGER;
BEGIN
    -- Sessao sem espaco definido nao conflita com nada
    IF NEW.EspacoId IS NULL THEN
        RETURN NEW;
    END IF;

    -- Serializa agendamentos concorrentes no mesmo espaco.
    -- Advisory lock (e nao FOR UPDATE em espaco) para nao entrar em conflito
    -- com o FOR SHARE de trg_sessao_requisitos, que roda antes.
    PERFORM pg_advisory_xact_lock(NEW.EspacoId);

    SELECT COUNT(*)
      INTO v_conflito
      FROM sessao
     WHERE EspacoId = NEW.EspacoId
       -- no UPDATE, ignora a propria sessao (identificada pela chave antiga)
       AND (TG_OP = 'INSERT'
            OR (AtividadeId, NumeroSessao) <> (OLD.AtividadeId, OLD.NumeroSessao))
       AND NEW.DataHoraInicio < DataHoraFim
       AND (NEW.DataHoraInicio + make_interval(mins => NEW.Duracao)) > DataHoraInicio;

    IF v_conflito > 0 THEN
        RAISE EXCEPTION 'Erro de agendamento: o espaco % ja possui outra sessao alocada neste horario.',
            NEW.EspacoId
            USING ERRCODE = 'check_violation';
    END IF;

    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DROP TRIGGER IF EXISTS trg_valida_conflito_espaco ON sessao;

CREATE TRIGGER trg_valida_conflito_espaco
BEFORE INSERT OR UPDATE OF EspacoId, DataHoraInicio, Duracao ON sessao
FOR EACH ROW
EXECUTE FUNCTION fn_valida_conflito_espaco();


-- ------------------------------------------------------------
-- Trigger 1: Conflito de horario na inscricao
-- A mesma pessoa nao pode ter inscricoes em sessoes sobrepostas
-- ------------------------------------------------------------
CREATE OR REPLACE FUNCTION fn_verifica_conflito_inscricao()
RETURNS TRIGGER AS $$
DECLARE
    v_participante INTEGER;
    v_inicio       TIMESTAMP;
    v_fim          TIMESTAMP;
    v_conf_nome    VARCHAR(150);
    v_conf_inicio  TIMESTAMP;
    v_conf_fim     TIMESTAMP;
BEGIN
    -- Descobre quem e a pessoa por tras do credenciamento
    SELECT ParticipanteId
      INTO v_participante
      FROM credenciamento
     WHERE CredenciamentoId = NEW.CredenciamentoId;

    -- Trava o participante para serializar inscricoes concorrentes da mesma pessoa
    PERFORM 1
       FROM participante
      WHERE ParticipanteId = v_participante
        FOR UPDATE;

    -- Intervalo da sessao que esta sendo inscrita
    SELECT DataHoraInicio, DataHoraFim
      INTO v_inicio, v_fim
      FROM sessao
     WHERE AtividadeId  = NEW.AtividadeId
       AND NumeroSessao = NEW.NumeroSessao;

    -- Procura qualquer outra inscricao da mesma pessoa cujo intervalo se sobreponha
    SELECT s.Nome, s.DataHoraInicio, s.DataHoraFim
      INTO v_conf_nome, v_conf_inicio, v_conf_fim
      FROM inscricao i
      JOIN credenciamento c ON c.CredenciamentoId = i.CredenciamentoId
      JOIN sessao s         ON s.AtividadeId      = i.AtividadeId
                           AND s.NumeroSessao     = i.NumeroSessao
     WHERE c.ParticipanteId = v_participante
       AND (TG_OP = 'INSERT' OR i.InscricaoId <> NEW.InscricaoId)
       AND s.DataHoraInicio < v_fim
       AND v_inicio         < s.DataHoraFim
     LIMIT 1;

    IF FOUND THEN
        RAISE EXCEPTION
            'Conflito de horario: o participante % ja esta inscrito na sessao "%" (% a %).',
            v_participante, v_conf_nome,
            to_char(v_conf_inicio, 'DD/MM/YYYY HH24:MI'),
            to_char(v_conf_fim,    'DD/MM/YYYY HH24:MI')
            USING ERRCODE = 'check_violation';
    END IF;

    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DROP TRIGGER IF EXISTS trg_inscricao_conflito_horario ON inscricao;

CREATE TRIGGER trg_inscricao_conflito_horario
BEFORE INSERT OR UPDATE OF CredenciamentoId, AtividadeId, NumeroSessao ON inscricao
FOR EACH ROW
EXECUTE FUNCTION fn_verifica_conflito_inscricao();


-- ------------------------------------------------------------
-- Trigger 2: Limite de vagas (inscricao com sessao)
-- Somente ouvintes ocupam vaga.
-- ------------------------------------------------------------
CREATE OR REPLACE FUNCTION fn_verifica_limite_vagas()
RETURNS TRIGGER AS $$
DECLARE
    v_vagas    INTEGER;
    v_ocupadas INTEGER;
BEGIN
    -- Somente ouvintes ocupam vaga: outros papeis passam direto
    IF NEW.Papel <> 'ouvinte' THEN
        RETURN NEW;
    END IF;

    -- Trava a linha da sessao para serializar inscricoes concorrentes
    -- (sem isso, duas transacoes simultaneas podem estourar o limite).
    SELECT Vagas
      INTO v_vagas
      FROM sessao
     WHERE AtividadeId  = NEW.AtividadeId
       AND NumeroSessao = NEW.NumeroSessao
       FOR UPDATE;

    -- Conta os ouvintes ja inscritos
    -- (no UPDATE, ignora a propria linha que esta sendo alterada).
    SELECT COUNT(*)
      INTO v_ocupadas
      FROM inscricao
     WHERE AtividadeId  = NEW.AtividadeId
       AND NumeroSessao = NEW.NumeroSessao
       AND Papel = 'ouvinte'
       AND (TG_OP = 'INSERT' OR InscricaoId <> NEW.InscricaoId);

    IF v_ocupadas >= v_vagas THEN
        RAISE EXCEPTION 'Sessao % da atividade % esgotada: % de % vagas preenchidas.',
            NEW.NumeroSessao, NEW.AtividadeId, v_ocupadas, v_vagas
            USING ERRCODE = 'check_violation';
    END IF;

    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DROP TRIGGER IF EXISTS trg_inscricao_limite_vagas ON inscricao;

-- Papel incluido: instrutor/palestrante que vira ouvinte passa a ocupar vaga
CREATE TRIGGER trg_inscricao_limite_vagas
BEFORE INSERT OR UPDATE OF AtividadeId, NumeroSessao, Papel ON inscricao
FOR EACH ROW
EXECUTE FUNCTION fn_verifica_limite_vagas();


-- ------------------------------------------------------------
-- Trigger 3 (em SESSAO): capacidade do espaco + recursos ja exigidos
-- ------------------------------------------------------------
CREATE OR REPLACE FUNCTION fn_verifica_requisitos_sessao()
RETURNS TRIGGER AS $$
DECLARE
    v_limite   INTEGER;
    v_recurso  VARCHAR(100);
    v_exigido  INTEGER;
    v_estoque  INTEGER;
BEGIN
    -- Sessao sem espaco definido nao tem requisitos a validar
    IF NEW.EspacoId IS NULL THEN
        RETURN NEW;
    END IF;

    -- FOR SHARE evita que o espaco seja alterado/removido durante a validacao
    SELECT LimitePessoas
      INTO v_limite
      FROM espaco
     WHERE EspacoId = NEW.EspacoId
       FOR SHARE;

    -- (a) Vagas da sessao nao podem exceder a capacidade do espaco
    IF NEW.Vagas > v_limite THEN
        RAISE EXCEPTION
            'Sessao "%": % vagas excedem o limite de % pessoas do espaco %.',
            NEW.Nome, NEW.Vagas, v_limite, NEW.EspacoId
            USING ERRCODE = 'check_violation';
    END IF;

    -- (b) Recursos que a sessao ja exige devem existir no estoque do espaco
    --     (no INSERT ainda nao ha recursos_sessao; vale para troca de espaco)
    SELECT r.Nome, rs.QtdNecessaria, COALESCE(e.Quantidade, 0)
      INTO v_recurso, v_exigido, v_estoque
      FROM recursos_sessao rs
      JOIN recursos r        ON r.RecursoId = rs.RecursoId
      LEFT JOIN estoque e    ON e.EspacoId  = NEW.EspacoId
                            AND e.RecursoId = rs.RecursoId
     WHERE rs.AtividadeId  = NEW.AtividadeId
       AND rs.NumeroSessao = NEW.NumeroSessao
       AND COALESCE(e.Quantidade, 0) < rs.QtdNecessaria
     LIMIT 1;

    IF FOUND THEN
        RAISE EXCEPTION
            'Espaco % nao atende a sessao "%": recurso "%" exige % unidade(s), mas ha %.',
            NEW.EspacoId, NEW.Nome, v_recurso, v_exigido, v_estoque
            USING ERRCODE = 'check_violation';
    END IF;

    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DROP TRIGGER IF EXISTS trg_sessao_requisitos ON sessao;

CREATE TRIGGER trg_sessao_requisitos
BEFORE INSERT OR UPDATE OF EspacoId, Vagas ON sessao
FOR EACH ROW
EXECUTE FUNCTION fn_verifica_requisitos_sessao();


-- ------------------------------------------------------------
-- Trigger 4 (em RECURSOS_SESSAO): o espaco da sessao tem o recurso?
-- ------------------------------------------------------------
CREATE OR REPLACE FUNCTION fn_verifica_recurso_sessao()
RETURNS TRIGGER AS $$
DECLARE
    v_espaco     INTEGER;
    v_disponivel INTEGER;
BEGIN
    -- FOR SHARE impede que o espaco da sessao mude durante a validacao
    SELECT EspacoId
      INTO v_espaco
      FROM sessao
     WHERE AtividadeId  = NEW.AtividadeId
       AND NumeroSessao = NEW.NumeroSessao
       FOR SHARE;

    -- Sessao sem espaco: nada a validar (sera validado quando o espaco for definido)
    IF v_espaco IS NULL THEN
        RETURN NEW;
    END IF;

    SELECT Quantidade
      INTO v_disponivel
      FROM estoque
     WHERE EspacoId  = v_espaco
       AND RecursoId = NEW.RecursoId;

    IF v_disponivel IS NULL THEN
        RAISE EXCEPTION
            'O espaco % nao possui o recurso % no estoque.',
            v_espaco, NEW.RecursoId
            USING ERRCODE = 'check_violation';
    ELSIF v_disponivel < NEW.QtdNecessaria THEN
        RAISE EXCEPTION
            'Recurso % insuficiente no espaco %: necessario %, disponivel %.',
            NEW.RecursoId, v_espaco, NEW.QtdNecessaria, v_disponivel
            USING ERRCODE = 'check_violation';
    END IF;

    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DROP TRIGGER IF EXISTS trg_recursos_sessao_requisitos ON recursos_sessao;

CREATE TRIGGER trg_recursos_sessao_requisitos
BEFORE INSERT OR UPDATE OF AtividadeId, NumeroSessao, RecursoId, QtdNecessaria ON recursos_sessao
FOR EACH ROW
EXECUTE FUNCTION fn_verifica_recurso_sessao();


-- ------------------------------------------------------------
-- Trigger 5 (em PESSOA_PROMOTOR e ORGANIZACAO): especializacao disjunta
-- Um promotor e pessoa fisica OU organizacao, nunca os dois.
-- ------------------------------------------------------------
CREATE OR REPLACE FUNCTION fn_verifica_promotor_disjunto()
RETURNS TRIGGER AS $$
DECLARE
    v_promotor INTEGER;
BEGIN
    IF TG_TABLE_NAME = 'pessoa_promotor' THEN
        v_promotor := NEW.PessoaPId;
    ELSE
        v_promotor := NEW.OrganizacaoId;
    END IF;

    -- Trava o promotor para que duas transacoes nao o especializem ao mesmo tempo
    PERFORM 1
       FROM promotor
      WHERE PromotorId = v_promotor
        FOR UPDATE;

    -- Procura o mesmo promotor na outra subclasse
    IF TG_TABLE_NAME = 'pessoa_promotor' THEN
        PERFORM 1 FROM organizacao     WHERE OrganizacaoId = v_promotor;
    ELSE
        PERFORM 1 FROM pessoa_promotor WHERE PessoaPId     = v_promotor;
    END IF;

    IF FOUND THEN
        RAISE EXCEPTION
            'Especializacao disjunta: o promotor % ja esta cadastrado como %.',
            v_promotor,
            CASE WHEN TG_TABLE_NAME = 'pessoa_promotor'
                 THEN 'organizacao' ELSE 'pessoa fisica' END
            USING ERRCODE = 'check_violation';
    END IF;

    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

DROP TRIGGER IF EXISTS trg_pessoa_promotor_disjunto ON pessoa_promotor;

CREATE TRIGGER trg_pessoa_promotor_disjunto
BEFORE INSERT OR UPDATE OF PessoaPId ON pessoa_promotor
FOR EACH ROW
EXECUTE FUNCTION fn_verifica_promotor_disjunto();

DROP TRIGGER IF EXISTS trg_organizacao_disjunto ON organizacao;

CREATE TRIGGER trg_organizacao_disjunto
BEFORE INSERT OR UPDATE OF OrganizacaoId ON organizacao
FOR EACH ROW
EXECUTE FUNCTION fn_verifica_promotor_disjunto();

CONSULTA 1: Ocupação e Taxa de Preenchimento das Sessões
OBJETIVO: Retorna a lista de todas as sessões cadastradas com a quantidade total de inscritos, o total de
vagas disponíveis e o percentual de ocupação do espaço.
SQL: 
SELECT 
    e.Nome AS Evento,
    a.Nome AS Atividade,
    s.NumeroSessao,
    s.DataHoraInicio,
    COALESCE(esp.Nome, 'Não definido') AS Espaco,
    s.Vagas AS VagasTotais,
    COUNT(i.InscricaoId) AS Inscritos,
    ROUND((COUNT(i.InscricaoId)::NUMERIC / NULLIF(s.Vagas, 0)) * 100, 2) AS PercentualOcupacao
FROM sessao s
JOIN atividade a ON s.AtividadeId = a.AtividadeId
JOIN evento e ON a.EventoId = e.EventoId
LEFT JOIN espaco esp ON s.EspacoId = esp.EspacoId
LEFT JOIN inscricao i ON s.AtividadeId = i.AtividadeId
	AND s.NumeroSessao = i.NumeroSessao
	AND i.Papel = 'ouvinte'
GROUP BY e.Nome, a.Nome, s.AtividadeId, s.NumeroSessao, s.DataHoraInicio, esp.Nome, s.Vagas
ORDER BY PercentualOcupacao DESC;

CONSULTA 2: Participantes com Múltiplas Inscrições e Papéis Desempenhados
OBJETIVO: Lista os participantes que estão inscritos em mais de uma sessão ou evento, detalhando seus
respectivos papéis e organização de origem.
SQL:
SELECT 
    p.Nome AS Participante,
    p.CPF,
    c.Organizacao,
    COUNT(DISTINCT c.EventoId) AS TotalEventosInscritos,
    COUNT(i.InscricaoId) AS TotalSessoesInscritas,
    STRING_AGG(DISTINCT i.Papel::TEXT, ', ') AS PapeisDesempenhados
FROM participante p
JOIN credenciamento c ON p.ParticipanteId = c.ParticipanteId
JOIN inscricao i ON c.CredenciamentoId = i.CredenciamentoId
GROUP BY p.ParticipanteId, p.Nome, p.CPF, c.Organizacao
HAVING COUNT(i.InscricaoId) > 1
ORDER BY TotalSessoesInscritas DESC;

CONSULTA 3: Ranking e Arrecadação Financeira por Evento
OBJETIVOS: Calcula o valor total captado via patrocínios e a receita bruta estimada gerada pela venda de
inscrições pagas em cada evento.
SQL: 
WITH ReceitaPatrocinio AS (
    SELECT 
        EventoId,
        SUM(Valor) AS TotalPatrocinio
    FROM patrocinio
    GROUP BY EventoId
),
ReceitaInscricoes AS (
    SELECT 
        a.EventoId,
        SUM(s.Valor) AS TotalInscricoes
    FROM inscricao i
    JOIN sessao s ON i.AtividadeId = s.AtividadeId
                 AND i.NumeroSessao = s.NumeroSessao
    JOIN atividade a ON s.AtividadeId = a.AtividadeId
    GROUP BY a.EventoId
)
SELECT 
    e.EventoId,
    e.Nome AS Evento,
    COALESCE(p.TotalPatrocinio, 0.00) AS ReceitaPatrocinio,
    COALESCE(i.TotalInscricoes, 0.00) AS ReceitaInscricoes,
    (COALESCE(p.TotalPatrocinio, 0.00) + COALESCE(i.TotalInscricoes, 0.00)) AS ReceitaTotal
FROM evento e
LEFT JOIN ReceitaPatrocinio p ON e.EventoId = p.EventoId
LEFT JOIN ReceitaInscricoes i ON e.EventoId = i.EventoId
ORDER BY ReceitaTotal DESC;

CONSULTA 4: Relatório de Ocupação por Espaço Físico e Capacidade Máxima
OBJETIVO: Para um espaço específico, calcula o número total de sessões agendadas, a capacidade física e a média de ocupação das sessões.
SQL: 
SELECT
    esp.Nome                              AS espaco,
    ev.Nome                               AS evento,
    a.Nome                                AS atividade,
    s.Nome                                AS sessao,
    s.DataHoraInicio::date                AS data,
    to_char(s.DataHoraInicio, 'HH24:MI') || ' - ' ||
    to_char(s.DataHoraFim,    'HH24:MI')  AS horario,
    s.Vagas                               AS vagas,
    COUNT(i.InscricaoId) FILTER (WHERE i.Papel = 'ouvinte') AS inscritos
FROM sessao s
JOIN espaco esp       ON esp.EspacoId  = s.EspacoId
JOIN atividade a      ON a.AtividadeId = s.AtividadeId
JOIN evento ev        ON ev.EventoId   = a.EventoId
LEFT JOIN inscricao i ON i.AtividadeId  = s.AtividadeId
                     AND i.NumeroSessao = s.NumeroSessao
WHERE s.EspacoId = 1
  AND s.DataHoraInicio >= CURRENT_TIMESTAMP
GROUP BY esp.Nome, ev.Nome, a.Nome, s.AtividadeId, s.NumeroSessao, s.Nome,
         s.DataHoraInicio, s.DataHoraFim, s.Vagas
ORDER BY s.DataHoraInicio;

CONSULTA 5: Demanda de recursos das sessões x estoque do espaço
OBJETIVO: Verifica se cada espaço tem os recursos que as sessões alocadas nele exigem, identificando faltas e sobras e classifica cada situação por gravidade.
SQL:
SELECT s.Nome                                   AS sessao,
       esp.Nome                                 AS espaco,
       r.Nome                                   AS recurso,
       rs.QtdNecessaria                         AS necessario,
       -- NULL quando a sessão não tem espaço (não se aplica)
       CASE WHEN s.EspacoId IS NOT NULL
            THEN COALESCE(e.Quantidade, 0) END  AS em_estoque,
       CASE WHEN s.EspacoId IS NOT NULL
            THEN COALESCE(e.Quantidade, 0) - rs.QtdNecessaria END AS folga,
       SUM(rs.QtdNecessaria) OVER (PARTITION BY rs.RecursoId)     AS demanda_total_do_recurso,
       CASE
           WHEN s.EspacoId IS NULL              THEN 'Sessão sem espaço'
           WHEN e.Quantidade IS NULL            THEN 'Recurso ausente no espaço'
           WHEN e.Quantidade < rs.QtdNecessaria THEN 'Insuficiente'
           WHEN e.Quantidade = rs.QtdNecessaria THEN 'Justo'
           ELSE 'Folgado'
       END                                      AS situacao
  FROM recursos_sessao rs
  JOIN sessao s         ON s.AtividadeId  = rs.AtividadeId
                       AND s.NumeroSessao = rs.NumeroSessao
  JOIN recursos r       ON r.RecursoId = rs.RecursoId
  LEFT JOIN espaco esp  ON esp.EspacoId = s.EspacoId
  LEFT JOIN estoque e   ON e.EspacoId  = s.EspacoId
                       AND e.RecursoId = rs.RecursoId
 ORDER BY CASE
              WHEN s.EspacoId IS NULL              THEN 1
              WHEN e.Quantidade IS NULL            THEN 2
              WHEN e.Quantidade < rs.QtdNecessaria THEN 3
              WHEN e.Quantidade = rs.QtdNecessaria THEN 4
              ELSE 5
          END,
          s.Nome, r.Nome;
